# Quantum Physics Through Coding
### QSTEP Hands-on Workshop | Purdue University

Welcome to the Quantum Physics Through Coding workshop!

This interactive workshop introduces fundamental concepts of quantum mechanics through simple Python simulations using [QuTiP](https://qutip.org/).

No prior experience with quantum computing or QuTiP is required. Basic familiarity with Python is helpful.

## What will we explore?

During this workshop, we will:

1. Understand how a two-level quantum system (qubit) can be represented on the Bloch sphere.
2. Explore quantum states and their time evolution.
3. Investigate how different Hamiltonians affect the motion of a qubit.
4. Simulate Rabi oscillations.
5. Explore spin echo and how quantum dynamics can be manipulated.

Students are encouraged to modify parameters, experiment with initial conditions, and observe how the resulting dynamics change.

## Getting Started

### Option 1: Run using nanoHUB (Recommended)

1. Download the `.ipynb` notebook from this GitHub repository by opening the notebook file and selecting **Download raw file**.
2. Visit [nanoHUB](https://nanohub.org/) and log in.
3. Launch a Jupyter environment with Python and QuTiP available.
4. Upload the downloaded `.ipynb` file using the Jupyter file browser.
5. Open the notebook and run the cells sequentially.
